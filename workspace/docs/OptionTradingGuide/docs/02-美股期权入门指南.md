# 美股期权入门指南

## 一、市场概述

### 1.1 什么是期权

期权（Option）是一种金融衍生合约，赋予持有者在特定时间内以特定价格买入或卖出标的资产的权利。

**核心要素：**
- **Call（认购期权）**：买入标的资产的权利
- **Put（认沽期权）**：卖出标的资产的权利
- **Strike Price（行权价）**：约定的买卖价格
- **Expiration Date（到期日）**：期权有效的最后日期
- **Premium（权利金）**：购买期权支付的价格

### 1.2 美股期权市场特点

**市场规模：**
- 全球最大的期权市场
- 日均交易量超过 4,000 万张合约
- 涵盖股票、ETF、指数等多种标的

**主要交易所：**
| 交易所 | 代码 | 特点 |
|--------|------|------|
| CBOE（芝加哥期权交易所） | CBOE | 全球最大期权交易所 |
| NYSE American | AMEX | 历史悠久 |
| NASDAQ OMX | PHLX | 科技股期权活跃 |
| MIAX | MIAX | 新兴交易所 |

**交易时间：**
- 常规交易：美东时间 9:30-16:00（北京时间 22:30-次日 5:00）
- 盘前交易：部分券商支持 4:00-9:30
- 盘后交易：部分券商支持 16:00-20:00

### 1.3 主要期权品种

**股票期权：**
- 苹果 (AAPL)、特斯拉 (TSLA)、英伟达 (NVDA) 等热门个股
- 流动性好，价差小

**ETF 期权：**
- SPY（标普 500ETF）
- QQQ（纳斯达克 100ETF）
- IWM（罗素 2000ETF）

**指数期权：**
- VIX（恐慌指数）
- SPX（标普 500 指数）
- NDX（纳斯达克 100 指数）

## 二、合约要素

### 2.1 基本合约规格

| 要素 | 规格 |
|------|------|
| 合约单位 | 100 股/张 |
| 报价单位 | 美元 |
| 最小变动价位 | $0.01 |
| 行权方式 | 美式（大多数股票期权） |
| 交割方式 | 实物交割（股票期权）/ 现金交割（指数期权） |
| 到期日 | 每月第三个星期五（周到期权除外） |

### 2.2 合约命名规则

**标准格式：** `标的 + 到期日 + 期权类型 + 行权价`

**示例：**
```
AAPL 240119 C 185
- 标的：AAPL（苹果）
- 到期日：2024 年 1 月 19 日
- 类型：C = Call（认购），P = Put（认沽）
- 行权价：$185
```

**OPRA 代码格式：**
```
AAPL240119C00185000
- 前 6 位：标的代码（不足补空格）
- 中间 6 位：到期日（YYMMDD）
- 第 13 位：C/P
- 后 5 位：行权价（×1000）
```

### 2.3 到期日类型

**月度期权（Monthly）：**
- 到期日：每月第三个星期五
- 流动性最好

**周度期权（Weekly）：**
- 到期日：每周五
- 适合短期交易

**末日期权（0DTE）：**
- 当日到期
- 高风险高波动

**长期期权（LEAPS）：**
- 到期日：1 年以上
- 适合长期策略

### 2.4 行权价格间距

| 价格范围 | 间距 |
|----------|------|
| <$25 | $2.50 |
| $25-$200 | $5 |
| $200-$500 | $10 |
| >$500 | $25 或更大 |

**特殊规则：**
- 热门股票可能有更密集的间距（如$1、$2.50）
- 随股价变动会加挂新的行权价

## 三、交易机制

### 3.1 交易类型

**买入开仓（Buy to Open）：**
- 支付权利金，获得期权权利
- Buy Call：看涨
- Buy Put：看跌

**卖出开仓（Sell to Open）：**
- 收取权利金，承担义务
- 需缴纳保证金
- Sell Call：看跌或中性
- Sell Put：看涨或中性

**买入平仓（Buy to Close）：**
- 了结卖出开仓的持仓

**卖出平仓（Sell to Close）：**
- 了结买入开仓的持仓

### 3.2 保证金制度

**买方：** 无需保证金，最大损失为权利金

**卖方保证金要求：**

**裸卖空（Naked Short）：**
```
保证金 = 权利金 + max(20% 标的价值 - 虚值额，10% 标的价值)
```

**备兑卖空（Covered）：**
- 卖出 Covered Call：需持有 100 股/张的标的股票
- 卖出 Cash-Secured Put：需持有行权价×100 的现金

**组合保证金（Portfolio Margin）：**
- 基于整体风险计算
- 资金利用率更高
- 需账户净值>$100,000

### 3.3 行权与指派

**行权（Exercise）：**
- 买方主动执行期权权利
- 美式期权：到期日前任何时间
- 欧式期权：仅到期日

**指派（Assignment）：**
- 卖方被动接受行权
- 由 OCC（期权清算公司）随机分配
- 可能发生在任何交易日

**自动行权规则：**
- 到期时实值≥$0.01 自动行权
- 可提前通知券商放弃行权

### 3.4 交割方式

**实物交割（Physical Delivery）：**
- 股票期权采用
- Call 行权：支付现金获得股票
- Put 行权：交付股票获得现金

**现金交割（Cash Settlement）：**
- 指数期权采用
- 直接结算差价
- 无需交付标的

## 五、基础策略

### 5.1 买入认购（Long Call）

**策略构成：** 买入 Call

**适用场景：** 强烈看涨，希望杠杆放大收益

**盈亏分析：**
- 最大盈利：无限
- 最大亏损：权利金
- 盈亏平衡点：行权价 + 权利金

**案例：**
```
AAPL 当前股价：$180
买入 1 张 AAPL $185 Call（30 天到期）
权利金：$5.00/股，总成本 = $5 × 100 = $500

情景 1：到期时 AAPL 涨至$200
盈利 = ($200 - $185 - $5) × 100 = $1,000
收益率 = $1,000 / $500 = 200%

情景 2：到期时 AAPL 为$182
期权作废，亏损 = $500（全部权利金）
```

### 5.2 买入认沽（Long Put）

**策略构成：** 买入 Put

**适用场景：** 强烈看跌，或为持仓对冲

**盈亏分析：**
- 最大盈利：行权价 - 权利金（股价跌至 0）
- 最大亏损：权利金
- 盈亏平衡点：行权价 - 权利金

**案例：**
```
持有 100 股 AAPL，成本$180
买入 1 张 AAPL $175 Put（30 天到期）
权利金：$4.00/股，成本 = $400

若 AAPL 跌至$160：
股票亏损 = ($180 - $160) × 100 = $2,000
Put 盈利 = ($175 - $160) × 100 - $400 = $1,100
净亏损 = $900（相比未保护的$2,000 大幅减少）
```

### 5.3 备兑认购（Covered Call）

**策略构成：** 持有 100 股股票 + 卖出 1 张 Call

**适用场景：** 持有股票，预期震荡或小幅上涨

**盈亏分析：**
- 最大盈利：权利金 + (行权价 - 股票成本)
- 最大亏损：股票成本 - 权利金
- 风险：股票大涨时收益被锁定

**案例：**
```
持有 100 股 AAPL，成本$175
卖出 1 张 AAPL $180 Call（30 天到期）
收取权利金：$3.00/股，收入 = $300

情景 1：到期时 AAPL 涨至$185
股票盈利 = ($180 - $175) × 100 = $500（被行权锁定）
权利金收入 = $300
总盈利 = $800，收益率 = $800 / $17,500 = 4.57%

情景 2：到期时 AAPL 跌至$170
股票亏损 = ($175 - $170) × 100 = $500
权利金收入 = $300
净亏损 = $200（权利金抵消部分亏损）
```

### 5.4 现金担保认沽（Cash-Secured Put）

**策略构成：** 卖出 Put + 预留行权价×100 现金

**适用场景：** 想低价买入股票，或赚取权利金

**盈亏分析：**
- 最大盈利：权利金
- 最大亏损：行权价 - 权利金（股价跌至 0）
- 风险：需按行权价买入股票

**案例：**
```
AAPL 当前股价：$180
想以$175 买入
卖出 1 张 AAPL $175 Put（30 天到期）
收取权利金：$4.00/股，收入 = $400
预留现金：$175 × 100 = $17,500

情景 1：到期时 AAPL 高于$175
Put 作废，盈利 = $400
收益率 = $400 / $17,500 = 2.29%（30 天）

情景 2：到期时 AAPL 跌至$170
被指派买入股票，成本 = $175 - $4 = $171/股
相比市价$170，实际成本更低
```

### 5.5 垂直价差（Vertical Spread）

**牛市看涨价差（Bull Call Spread）：**
```
买入低行权价 Call + 卖出高行权价 Call（同期限）

最大盈利 = 行权价差额 - 净权利金
最大亏损 = 净权利金
```

**熊市看跌价差（Bear Put Spread）：**
```
买入高行权价 Put + 卖出低行权价 Put（同期限）

最大盈利 = 行权价差额 - 净权利金
最大亏损 = 净权利金
```

**案例 - Bull Call Spread：**
```
AAPL 当前股价：$180
买入 1 张 $180 Call，权利金$6.00
卖出 1 张 $190 Call，权利金$2.50
净成本 = ($6.00 - $2.50) × 100 = $350

最大盈利 = ($190 - $180 - $3.50) × 100 = $650
最大亏损 = $350
收益率 = $650 / $350 = 186%
```

## 六、风险管理

### 6.1 仓位管理

**基本原则：**
- 单笔交易不超过总资金的 5%
- 买方策略：权利金总额≤10%
- 卖方策略：保证金占用≤30%

**仓位计算公式：**
```
合理仓位 = 总资金 × 风险比例 / 单笔最大亏损
```

### 6.2 止损策略

**买方止损：**
- 权利金损失 50% 时考虑止损
- 标的价格突破关键技术位时止损
- 到期前 7 天虚值期权考虑平仓

**卖方止损：**
- 浮亏达到权利金 2 倍时止损
- 标的价格突破关键位时平仓
- 保证金不足时及时补充或平仓

### 6.3 希腊字母风险

| 希腊字母 | 含义 | 风险管理 |
|----------|------|----------|
| Delta | 价格敏感度 | 控制方向性风险 |
| Gamma | Delta 变化率 | 避免临近到期大 Gamma |
| Theta | 时间衰减 | 买方注意时间损耗 |
| Vega | 波动率敏感度 | 波动率高时谨慎买期权 |

## 八、税务考虑

### 8.1 美国税务规则

**短期资本利得：**
- 持有期<1 年
- 按普通所得税率征收

**长期资本利得：**
- 持有期>1 年
- 税率较低（0%、15%、20%）

**Section 1256 合约：**
- 指数期权适用
- 60% 长期 +40% 短期，无论持有期

### 8.2 中国投资者税务

**美股期权收益：**
- 目前中国暂无明确征税规定
- 建议咨询专业税务顾问

**信息申报：**
- 大额海外投资需申报
- 遵守外汇管理规定
