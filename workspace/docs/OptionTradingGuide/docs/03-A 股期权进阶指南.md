# A 股期权进阶指南

## 一、希腊字母（The Greeks）

### 1.1 什么是希腊字母

希腊字母是衡量期权风险的各项指标，帮助交易者量化和管理风险。

### 1.2 Delta（Δ）- 方向敏感度

**定义：** 标的价格变动 1 元时期权价格的变动量

**特点：**
- Call Delta：0 到 1（实值接近 1，虚值接近 0）
- Put Delta：-1 到 0（实值接近 -1，虚值接近 0）
- 平值期权 Delta 约±0.5

**应用：**
```
50ETF 价格 2.600 元
认购期权 Delta = 0.6

若 50ETF 上涨 0.1 元：
期权价格变动 ≈ 0.6 × 0.1 = 0.06 元
```

**Delta 对冲：**
- 持有 10,000 份 50ETF（Delta=10,000）
- 卖出 Delta=0.5 的认购期权 20 张
- 组合 Delta ≈ 10,000 - (0.5 × 10,000 × 20) = 0（Delta 中性）

### 1.3 Gamma（Γ）- Delta 变化率

**定义：** 标的价格变动 1 元时 Delta 的变动量

**特点：**
- 平值期权 Gamma 最大
- 临近到期 Gamma 急剧增大
- 买方 Gamma 为正，卖方 Gamma 为负

**风险：**
```
持有 Call，Gamma = 0.5

50ETF 从 2.600 涨至 2.700：
Delta 从 0.5 增至 0.5 + (0.5 × 0.1) = 0.55

继续上涨时，盈利加速（Gamma 收益）
下跌时，亏损减速（Gamma 保护）
```

**Gamma 风险：**
- 卖方临近到期面临 Gamma 风险
- 标的大幅波动时 Delta 快速变化
- 需频繁调整对冲头寸

### 1.4 Theta（Θ）- 时间衰减

**定义：** 每过一天期权价值的减少量

**特点：**
- 买方 Theta 为负（时间损耗）
- 卖方 Theta 为正（时间收益）
- 临近到期 Theta 加速

**计算示例：**
```
持有 Call，Theta = -0.005

每天时间损耗 = 0.005 元/份
每张合约每天损耗 = 0.005 × 10,000 = 50 元

若持有 10 张，每天损耗 = 500 元
```

**Theta 策略：**
- 买方：选择流动性好的近期合约，快进快出
- 卖方：卖出近期期权，赚取时间价值

### 1.5 Vega（ν）- 波动率敏感度

**定义：** 隐含波动率变动 1% 时期权价格的变动量

**特点：**
- 买方 Vega 为正（波动率上升受益）
- 卖方 Vega 为负（波动率上升受损）
- 长期期权 Vega 更大

**应用：**
```
持有 Call，Vega = 0.03

隐含波动率从 20% 升至 25%：
期权价格变动 ≈ 0.03 × 5 = 0.15 元/份
每张合约盈利 = 0.15 × 10,000 = 1,500 元
```

**Vega 对冲：**
- 波动率高时：减少买方头寸，增加卖方头寸
- 波动率低时：增加买方头寸

### 1.6 Rho（ρ）- 利率敏感度

**定义：** 无风险利率变动 1% 时期权价格的变动量

**特点：**
- Call Rho 为正（利率上升，Call 升值）
- Put Rho 为负（利率上升，Put 贬值）
- 短期期权 Rho 影响较小

## 二、波动率分析

### 2.1 波动率类型

**历史波动率（Historical Volatility, HV）：**
- 基于过去价格计算
- 反映实际波动程度
- 计算方法：标准差年化

**隐含波动率（Implied Volatility, IV）：**
- 从期权价格反推
- 反映市场预期
- 期权定价的关键输入

**波动率曲面（Volatility Surface）：**
- 不同行权价和到期日的 IV 分布
- 呈现"波动率微笑"或"偏斜"

### 2.2 波动率指标

**中国波指（iVIX）：**
- 上交所发布的 50ETF 期权隐含波动率指数
- 类似美股 VIX
- 反映市场恐慌程度

**IV 百分位：**
```
当前 IV = 25%
过去 1 年 IV 范围：15% - 35%
IV 百分位 = (25-15)/(35-15) = 50%

解读：当前波动率处于中等水平
```

**IV Rank：**
- 当前 IV 在过去 1 年中的排名
- 高于 50%：波动率偏高，考虑卖出
- 低于 50%：波动率偏低，考虑买入

### 2.3 波动率交易策略

**做多波动率：**
- 买入跨式（Long Straddle）
- 买入宽跨式（Long Strangle）
- 适用场景：预期大波动但方向不明

**做空波动率：**
- 卖出跨式（Short Straddle）
- 卖出宽跨式（Short Strangle）
- 适用场景：预期震荡

**波动率套利：**
- 利用不同合约 IV 差异
- 利用 ETF 期权与股指期权 IV 差异

### 2.4 波动率均值回归

**规律：**
- 波动率具有均值回归特性
- 极端高/低 IV 往往会回归

**交易思路：**
```
当前 IV = 35%（历史 90% 分位）
预期 IV 将下降

策略：卖出期权（Short Vega）
- 卖出跨式
- 卖出宽跨式
- 卖出铁鹰
```

## 三、组合策略

### 3.1 跨式策略（Straddle）

**买入跨式（Long Straddle）：**
```
构成：买入平值 Call + 买入平值 Put（同期限）

最大亏损：权利金总额
最大盈利：无限
盈亏平衡点：行权价 ± 总权利金

适用：预期大波动，方向不明
```

**案例：**
```
50ETF 价格 2.600 元
买入 1 张 2600 Call，权利金 0.0800
买入 1 张 2600 Put，权利金 0.0700
总成本 = (0.0800 + 0.0700) × 10,000 = 1,500 元

盈亏平衡点：
上平衡点 = 2.600 + 0.1500 = 2.750
下平衡点 = 2.600 - 0.1500 = 2.450

若 50ETF 涨至 2.800：
Call 盈利 = (2.800 - 2.600) × 10,000 - 800 = 1,200 元
Put 作废，亏损 700 元
净盈利 = 1,200 - 700 = 500 元
```

**卖出跨式（Short Straddle）：**
```
构成：卖出平值 Call + 卖出平值 Put

最大盈利：权利金总额
最大亏损：无限
适用：预期震荡，波动率下降
```

### 3.2 宽跨式策略（Strangle）

**与跨式区别：**
- 使用虚值期权（Call 行权价 > Put 行权价）
- 成本更低
- 需要更大波动才能盈利

**买入宽跨式案例：**
```
50ETF 价格 2.600 元
买入 1 张 2700 Call，权利金 0.0400
买入 1 张 2500 Put，权利金 0.0350
总成本 = (0.0400 + 0.0350) × 10,000 = 750 元

盈亏平衡点：
上平衡点 = 2.700 + 0.0750 = 2.775
下平衡点 = 2.500 - 0.0750 = 2.425
```

### 3.3 价差策略（Spread）

**牛市看涨价差（Bull Call Spread）：**
```
构成：买入低行权价 Call + 卖出高行权价 Call

最大盈利 = 行权价差额 - 净权利金
最大亏损 = 净权利金
```

**案例：**
```
50ETF 价格 2.600 元
买入 1 张 2600 Call，权利金 0.0800
卖出 1 张 2700 Call，权利金 0.0400
净成本 = (0.0800 - 0.0400) × 10,000 = 400 元

最大盈利 = (2.700 - 2.600 - 0.0400) × 10,000 = 600 元
最大亏损 = 400 元
收益率 = 600 / 400 = 150%
```

**熊市看跌价差（Bear Put Spread）：**
```
构成：买入高行权价 Put + 卖出低行权价 Put

最大盈利 = 行权价差额 - 净权利金
最大亏损 = 净权利金
```

**日历价差（Calendar Spread）：**
```
构成：卖出近期 Call + 买入远期 Call（同行权价）

盈利来源：近期 Theta 衰减更快
适用：预期短期震荡，长期方向不变
```

### 3.4 铁鹰策略（Iron Condor）

**构成：**
```
卖出虚值 Call + 买入更虚值 Call（熊市看涨价差）
+
卖出虚值 Put + 买入更虚值 Put（牛市看跌价差）
```

**特点：**
- 四腿组合
- 有限风险，有限收益
- 预期区间震荡

**案例：**
```
50ETF 价格 2.600 元

Call 端：
卖出 1 张 2700 Call，收取 0.0400
买入 1 张 2800 Call，支付 0.0200
Call 端净收入 = 0.0200 × 10,000 = 200 元

Put 端：
卖出 1 张 2500 Put，收取 0.0350
买入 1 张 2400 Put，支付 0.0150
Put 端净收入 = 0.0200 × 10,000 = 200 元

总权利金收入 = 400 元

最大盈利 = 400 元（到期时 50ETF 在 2500-2700 之间）
最大亏损 = (100 - 40) × 10,000 - 400 = 5,600 元
（任一端被突破时的损失）
```

### 3.5 蝶式策略（Butterfly）

**买入蝶式（Long Butterfly）：**
```
构成：
买入 1 张低行权价 Call
卖出 2 张中行权价 Call
买入 1 张高行权价 Call
（行权价等间距）

最大盈利：在中行权价时
最大亏损：净权利金
适用：预期标的停留在特定价格
```

**案例：**
```
50ETF 价格 2.600 元

买入 1 张 2500 Call，支付 0.1200
卖出 2 张 2600 Call，收取 2 × 0.0700 = 0.1400
买入 1 张 2700 Call，支付 0.0350
净成本 = (0.1200 - 0.1400 + 0.0350) × 10,000 = 150 元

最大盈利（到期价=2600）：
= (2.600 - 2.500) × 10,000 - 150 = 850 元

最大亏损 = 150 元
```

## 四、风险管理

### 4.1 仓位管理原则

**资金分配：**
```
总资金 100 万元

保守型：
- 期权买方：≤10%（10 万）
- 期权卖方：≤20% 保证金（20 万）
- 标的持仓：≥50%

激进型：
- 期权买方：≤20%
- 期权卖方：≤40% 保证金
- 标的持仓：≥30%
```

**单笔风险：**
- 单笔交易最大亏损≤总资金的 2%
- 单一标的期权持仓≤总资金的 10%

### 4.2 止损策略

**买方止损：**
| 止损类型 | 触发条件 | 操作 |
|----------|----------|------|
| 比例止损 | 权利金损失 50% | 平仓 |
| 时间止损 | 到期前 7 天仍虚值 | 平仓 |
| 技术止损 | 标的突破关键位 | 平仓 |
| 波动止损 | IV 大幅下降 | 考虑平仓 |

**卖方止损：**
| 止损类型 | 触发条件 | 操作 |
|----------|----------|------|
| 浮亏止损 | 浮亏达权利金 2 倍 | 平仓或展期 |
| 保证金止损 | 保证金不足 | 补充或减仓 |
| 技术止损 | 标的突破关键位 | 平仓 |
| 波动止损 | IV 大幅上升 | 考虑平仓 |

### 4.3 压力测试

**情景分析：**
```
当前持仓：
- 买入 10 张 2600 Call（50ETF 现价 2.600）
- 权利金成本 0.0800，总投入 8,000 元

压力测试：
情景 1：50ETF 跌 5% 至 2.470
期权价值 ≈ 0.0200，亏损 6,000 元（-75%）

情景 2：50ETF 涨 5% 至 2.730
期权价值 ≈ 0.1500，盈利 7,000 元（+87.5%）

情景 3：IV 从 20% 降至 15%
期权价值下降约 25%
```

**极端情景：**
- 标的跌停/涨停
- 波动率暴涨/暴跌
- 流动性枯竭

### 4.4 对冲策略

**Delta 对冲：**
```
持仓：买入 10 张 Call，总 Delta = 0.6 × 10 × 10,000 = 60,000

对冲：卖出 60,000 份 50ETF（或 6 张期货合约）

组合 Delta ≈ 0（市场中性）
```

**Vega 对冲：**
```
持仓：净 Vega = +500（做多波动率）

对冲：卖出跨式期权，Vega = -500

组合 Vega ≈ 0（波动率中性）
```

## 五、实战技巧

### 5.1 合约选择

**到期日选择：**
- 短线交易：1-4 周
- 中线交易：1-3 个月
- 长线交易：3 个月以上（LEAPS）

**行权价选择：**
- 买方：选择 Delta 0.3-0.7 的合约
- 卖方：选择 Delta 0.2-0.3 的合约

**流动性考虑：**
- 选择成交量大的合约
- 买卖价差小的合约
- 避免深度虚值/实值

### 5.2 时机选择

**买入时机：**
- IV 处于低位（IV Rank < 30%）
- 技术面突破前
- 重大事件前（财报、政策）

**卖出时机：**
- IV 处于高位（IV Rank > 70%）
- 横盘震荡时
- 事件风险消退后

### 5.3 展期策略

**向上/向下展期：**
```
原持仓：卖出 2600 Call
标的上涨后，买回 2600 Call，卖出 2700 Call

目的：锁定部分盈利，降低风险
```

**向前展期：**
```
原持仓：卖出本月 2600 Call
临近到期，买回本月 Call，卖出下月 2600 Call

目的：继续赚取时间价值
```

### 5.4 组合调整

**动态对冲：**
- 定期调整 Delta 至目标值
- 根据市场变化调整 Vega 敞口

**盈利保护：**
- 浮盈达到一定比例后，部分平仓
- 将买方头寸转为价差，锁定利润

## 六、交易心理

### 6.1 常见心理陷阱

**过度自信：**
- 连续盈利后加大仓位
- 忽视风险管理

**损失厌恶：**
- 亏损头寸不愿止损
- 盈利头寸过早平仓

**锚定效应：**
- 过度依赖买入成本
- 忽视当前市场状况

**从众心理：**
- 盲目跟随市场热点
- 缺乏独立判断

### 6.2 心理建设

**交易计划：**
- 入场前明确策略和止损
- 严格执行计划

**情绪管理：**
- 亏损后暂停交易
- 避免报复性交易

**持续学习：**
- 记录交易日志
- 定期复盘总结

---

*进阶交易需要扎实的基础和严格的风险管理。建议先在模拟环境中充分练习，再逐步过渡到实盘交易。*
