# 期权策略与不同波动率场景适配

## 场景 1：低波动率 + 预期波动率上行

**适用标的**：隐波低于历史均值（如 30%-35% 以下）、且预期标的会有波动的 ETF/个股

**核心策略**：做多波动率（赚隐波上涨 + 标的波动的钱）

### 推荐策略

| 策略 | 说明 |
|------|------|
| 买入跨式期权 | 同时买平值认购期权 + 平值认沽期权（到期日选 1-2 个月） |
| 买入宽跨式期权 | 同时买轻度虚值认购 + 轻度虚值认沽（风险比跨式小，成本更低） |

### 操作要点
- 小仓位参与（最大损失是权利金）
- 标的波动越大、隐波涨得越多，盈利越明显

### 风险提示
- 若标的横盘，时间价值会持续损耗，需及时止盈止损

## 场景 2：高波动率 + 预期波动率下行

**适用标的**：隐波高于历史 80% 分位数（如 40% 以上）、且预期标的波动会收窄

**核心策略**：做空波动率（赚隐波回落 + 时间价值损耗的钱）

### 推荐策略

| 策略 | 说明 |
|------|------|
| 卖出跨式期权 | 同时卖平值认购期权 + 平值认沽期权（到期日选 1 个月内） |
| 卖出铁鹰策略 | 卖轻度虚值认购 + 卖轻度虚值认沽，同时买更虚值的认购/认沽（对冲极端风险） |

### 操作要点
- 控制仓位（做空风险理论上无限）
- 标的在平值附近震荡时盈利最稳

### 风险提示
- 若标的大幅涨跌，可能产生巨额亏损，需设置止损（如标的偏离平值 5% 时平仓）

---

## 场景 3：波动率震荡（横盘）

**适用标的**：隐波在 35%-40% 之间、标的走势平稳

**核心策略**：赚时间价值

### 推荐策略

| 策略 | 说明 |
|------|------|
| 卖出看涨期权（备兑） | 持有标的现货，同时卖轻度虚值认购期权（赚取权利金，降低持仓成本） |
| 卖出看跌期权（现金担保） | 用现金做担保，卖轻度虚值认沽期权（若标的不跌穿行权价，白赚权利金） |

### 操作要点
- 选流动性好的合约
- 到期日 15-30 天最佳

---

## 场景 4：波动率极端异动（突发大涨/大跌）

**适用标的**：突发消息驱动的 ETF/个股（如政策利好、业绩暴雷）

**核心策略**：快进快出，抓短期波动

### 推荐策略

| 策略 | 说明 |
|------|------|
| 追涨/杀跌 | 方向明确时，直接买实值认购（看涨）或实值认沽（看跌），到期日选 1 周内（避免时间损耗） |
| 止盈已持有的波动率多头 | 若之前买了跨式/宽跨，此时隐波+标的波动双升，及时平仓锁定利润 |

### 操作要点
- 不恋战，极端波动后隐波通常会快速回落
