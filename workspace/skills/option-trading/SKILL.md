### 2. 实时期权数据获取

**可通过以下工具获取实时数据：**

#### A 股期权数据（tushare）
```
tushare 提供以下期权数据接口：
- 期权分钟行情：实时和历史分钟级行情
- 期权合约信息：合约基本信息（行权价、到期日等）
- 期权日线行情：历史日线数据
```

**获取 50ETF 期权数据示例：**
```bash
# 期权合约信息
tushare 期权合约信息

# 期权日线行情
tushare 期权日线行情 --标的 510050
```

#### 美股期权数据（fmp）
```
fmp 提供美股期权数据：
- 期权链（Option Chain）
- 期权定价
- 未平仓合约（Open Interest）
- 成交量（Volume）
```

**获取美股期权数据示例：**
```bash
# 期权链
fmp options AAPL

# 特定到期日的期权
fmp options AAPL --expiration 2026-03-20
```

## 常用公式速查

### 盈亏平衡点

| 策略 | 公式 |
|------|------|
| 买入 Call | 行权价 + 权利金 |
| 买入 Put | 行权价 - 权利金 |
| 卖出 Call | 行权价 + 权利金 |
| 卖出 Put | 行权价 - 权利金 |

### 希腊字母特征

| 字母 | 买方 | 卖方 |
|------|------|------|
| Delta | 方向性收益 | 方向性损失 |
| Gamma | 加速盈亏 | 加速盈亏 |
| Theta | 时间价值损耗 | 时间价值收益 |
| Vega | IV 上涨受益 | IV 下跌受益 |

### 资金管理

|------|------|
| 单笔最大亏损 | ≤ 2% |
| 单日最大亏损 | ≤ 5% |
| 单月最大亏损 | ≤ 20% |

### 场景 1：新手入门

**用户**：我想学期权，但什么都不懂

**回复**：
欢迎学习期权！建议从以下顺序开始：

1. **先了解基础概念**
   - 期权是一种选择权，持有者有权在约定时间以约定价格买入或卖出标的
   - Call（认购期权）= 看涨期权
   - Put（认沽期权）= 看跌期权

2. **推荐学习路径**

   - 先从简单策略开始（备兑开仓、保护性认沽）

### 场景 2：策略咨询

**用户**：我持有 50ETF，现在觉得会涨但也可能跌，想保险一点怎么办？

**回复**：

可以考虑 **保护性认沽（Protective Put）** 策略：

**策略说明**：
- 持有 50ETF 现货
- 买入轻度虚值 Put 作为保险

**优点**：
- 下跌风险有限（最大损失 = 标的价格 - 行权价 + 权利金）
- 上涨时享受全部收益
- 适合担心短期下跌但长期看好的人

**操作示例**：
- 持有 50ETF 价格 2.90 元
- 买入 2.85 行权价 Put，付权利金 0.04 元
- 最大损失：2.90 - 2.85 + 0.04 = 0.09 元/股

**注意**：
- Put 会消耗成本（权利金）
- 如果横盘或小幅上涨，可能亏损权利金

### 场景 3：波动率观点

**用户**：现在市场波动率很低，后面可能会放大，有什么策略？

**回复**：

低波动率 + 预期波动率上行 = **做多波动率策略**

**推荐策略**：

| 策略 | 风险 | 希腊字母 | 适用场景 |
|------|------|----------|----------|
| 买入跨式 | 中等 | +Gamma, +Vega | 预期大幅波动，不确定方向 |
| 买入宽跨式 | 中低 | +Gamma, +Vega | 预期波动但幅度不确定 |

**买入跨式策略**：
- 同时买入平值 Call + 平值 Put
- 标的大涨或大跌都能盈利
- 需要隐波上涨 + 标的大幅波动

**操作要点**：
- 到期日选择 1-2 个月
- 隐波低于 25% 是较好时机
- 仓位控制，单笔不超过 3%

**风险**：
- 横盘会亏损全部权利金
- 时间价值损耗

### 场景 4：资金管理

**用户**：期权仓位应该怎么控制？

**回复**：

期权仓位控制原则：

**基础规则**：

| 规则 | 比例 | 说明 |
|------|------|------|
| 单笔交易 | ≤ 2% | 总资金的 2% 作为单笔最大亏损 |
| 单日交易 | ≤ 5% | 单日亏损达到 5% 当日停止交易 |
| 单月交易 | ≤ 20% | 单月亏损达到 20% 当月停止交易 |

**策略仓位**：

| 策略类型 | 建议仓位 | 说明 |
|----------|----------|------|
| 买方策略 | 1-3% | 风险有限，可适当放松 |
| 卖方策略 | 10-20% | 风险较大，需严格控制 |
| 价差策略 | 5-10% | 中等风险 |

**仓位调整**：
- 新手建议更低仓位（50%）
- 盈利后可适当放大仓位
- 连续亏损后缩小仓位

**核心原则**：
- 绝不扭盈为亏
- 盈利单不要再变亏损
- 亏损后先总结再交易
