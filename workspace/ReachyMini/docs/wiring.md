## I2C 设备接线

### PCA9685 舵机驱动板

| PCA9685 | 树莓派 | 说明 |
|---------|--------|------|
| VCC | 3.3V | 电源 |
| GND | GND | 地 |
| SDA | GPIO 2 (SDA) | I2C数据 |
| SCL | GPIO 3 (SCL) | I2C时钟 |

**I2C地址**: 0x40 (默认)

### MPU6050 IMU 模块

| MPU6050 | 树莓派 | 说明 |
|---------|--------|------|
| VCC | 3.3V | 电源 |
| GND | GND | 地 |
| SDA | GPIO 2 (SDA) | I2C数据 |
| SCL | GPIO 3 (SCL) | I2C时钟 |

**I2C地址**: 0x68 (默认)

## 舵机接线 (PCA9685 通道)

| 通道 | 舵机 | 功能 | GPIO | 说明 |
|------|------|------|------|------|
| CH0 | DS5160 | 机身360°旋转 | - | 大扭矩 |
| CH1 | DS3231MG | 颈部-前左 | - | 6自由度 |
| CH2 | DS3231MG | 颈部-前右 | - | |
| CH3 | DS3231MG | 颈部-后左 | - | |
| CH4 | DS3231MG | 颈部-后右 | - | |
| CH5 | DS3231MG | 颈部-左 | - | |
| CH6 | DS3231MG | 颈部-右 | - | |
| CH7 | SG90 | 天线-偏航 | - | 左右摇摆 |
| CH8 | SG90 | 天线-俯仰 | - | 上下点头 |

**舵机线序** (标准3Pin):
```
┌───┐
│棕 │ → GND (地)
│红 │ → VCC (7.4V 舵机电源)
│橙 │ → 信号 (PCA9685输出)
└───┘
```

## 电源接线

### 分电方案 (必须分路!)

```
┌─────────────────────────────────────────────┐
│              电源系统接线                   │
├─────────────────────────────────────────────┤
│                                             │
│   ┌──────────────┐                         │
│   │  锂电池      │                         │
│   │  7.4V 2S    │                         │
│   │  (+/-)       │                         │
│   └──────┬───────┘                         │
│          │                                  │
│   ┌──────▼───────┐                         │
│   │ TP4056        │ 充电/保护板             │
│   │ 2S            │                         │
│   │               │                         │
│   │ B+ → B+      │ ← 电池正               │
│   │ B- → B-      │ ← 电池负               │
│   │ OUT+ → OUT+  │ → 输出正                │
│   │ OUT- → OUT-  │ → 输出负                │
│   └──────┬───────┘                         │
│          │                                  │
│   ┌──────▼───────┐    ┌───────────────┐   │
│   │ LM2596        │    │ 舵机电源      │   │
│   │ 降压模块      │───→│ 7.4V 直通    │   │
│   │ 输入: 7.4V   │    │               │   │
│   │ 输出: 5V 3A  │    └───────────────┘   │
│   └──────┬───────┘                         │
│          │                                  │
│   ┌──────▼───────┐                         │
│   │ 树莓派        │                         │
│   │ Type-C /     │                         │
│   │ GPIO 5V+ GND │                         │
│   └──────────────┘                         │
│                                             │
└─────────────────────────────────────────────┘
```

### 重要提醒

⚠️ **必须分两路供电:**
1. **舵机动力电**: 7.4V 直接供电 (不经降压)
2. **主控电**: 5V 降压后供电

⚠️ **严禁**:
- 舵机和树莓派共用同一组电源
- 7.4V 直接接到树莓派
