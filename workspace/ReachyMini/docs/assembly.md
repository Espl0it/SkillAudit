## 机械结构组装

> ⚠️ **重要提示**：所有机械结构组装必须在断电状态下进行

### 步骤1：机身底座与1自由度旋转机构

1. **底座预处理**
   - 底板放平，安装防滑脚垫
   - 预留电池、电源板、主控板安装位
   - 打好过线孔

2. **核心旋转件安装**
   - DS5160大扭矩舵机垂直固定在底座中心
   - 输出轴朝上
   - 深沟球轴承嵌套在上盖板中心孔

3. **旋转支架装配**
   - 舵机输出轴与旋转支架通过联轴器固定
   - 手动测试360°旋转无卡顿

4. **线材预理**
   - 舵机3Pin线从预留孔穿入
   - 预留足够旋转余量
   - 用扎带临时固定

> ⚠️ **提示**：舵机先不锁死最终螺丝，后续软件调零后再紧固

---

### 步骤2：6自由度斯图尔特平台 (颈部核心)

#### 2.1 舵机中位校准 (必做)

1. 取6个DS3231MG金属舵机
2. 逐个接入舵机测试仪，通5V电压
3. 全部调整至标准中位 (脉宽1500μs，对应90°)
4. 用笔标记舵盘与舵机壳体的对齐线

#### 2.2 下平台固定
- 铝合金下平台通过M3螺丝水平紧固在旋转支架顶面
- 确保下平台中心与机身旋转中心同轴

#### 2.3 舵机基座安装
- 6个校准好的舵机两两对称固定
- 舵机输出轴朝向平台外侧

#### 2.4 连杆与上平台装配
- 6根双球头连杆连接舵机和上平台
- 调整所有连杆长度一致
- 确保上平台绝对水平

> ⚠️ **警告**：严禁强行掰动舵机输出轴，防止损坏齿轮

---

### 步骤3：2自由度天线机构

1. **舵机校准**：2个SG90微型舵机校准至中位 (90°)
2. **基座固定**：天线底座支架螺丝固定在斯图尔特上平台
3. **双自由度装配**：
   - 第一个舵机负责左右偏航
   - 第二个舵机负责上下俯仰
4. **测试与理线**：手动测试两个自由度全程无干涉

---

### 步骤4：整机结构与外壳总装

1. **传感器固定**：摄像头支架安装，IMU模块安装位
2. **音频部件固定**：喇叭和功放板固定
3. **外壳闭合**：安装底座上盖板、侧围外壳
4. **线材整理**：按功能分类，用扎带束线固定

## 电气系统接线

> ⚠️ **警告**：全程断电操作！错误接线会直接烧毁元件

### 核心供电规则

**必须分两路隔离：**
- 舵机动力供电：7.4V
- 主控与外设供电：5V

**严禁共用同一组电源！**

---

### 接线步骤

#### 1. 电源模块组装

```
锂电池 (7.4V)
    ↓
TP4056 充电保护板
    ├──→ 舵机供电 (7.4V)
    └──→ LM2596 降压模块 → 5V → 树莓派
```

#### 2. 舵机控制信号接线

| 舵机 | PCA9685通道 |
|------|-------------|
| 机身旋转 | CH0 |
| 颈部6个 | CH1-CH6 |
| 天线2个 | CH7-CH8 |

#### 3. I2C设备接线

| 设备 | 树莓派引脚 |
|------|-----------|
| PCA9685 | SDA→GPIO2, SCL→GPIO3 |
| MPU6050 | SDA→GPIO2, SCL→GPIO3 |

---

### 最终安全检查

- [ ] 用万用表测量电源正负极之间电阻，无短路
- [ ] 核对所有接线极性，无反接
- [ ] 所有设备GND共地
- [ ] 杜邦线插装到位无松动

## 安全规范

### ⚠️ 关键警告

1. **所有接线、拆装必须在断电状态下进行**
2. **锂电池严禁过充、过放、短路**
3. **舵机运动时严禁用手强行掰动**
4. **首次调试必须先断开舵机动力电**

### 常见问题

| 故障 | 排查方向 |
|------|----------|
| 舵机不动作 | 供电不足/信号线接反/中位校准错误 |
| 树莓派不开机 | 供电不足/TF卡故障/GPIO短路 |
| 摄像头无画面 | 排线接反/Camera接口未开启 |
| I2C设备无法识别 | I2C接口未开启/设备地址冲突 |

## 附录

### GPIO 引脚定义

```
 GPIO2  → SDA (I2C)
 GPIO3  → SCL (I2C)
 GPIO14 → TXD (串口)
 GPIO15 → RXD (串口)
 GPIO18 → PWM (舵机信号)
```

### 舵机供电接线

```
棕色线 → GND
红色线 → VCC (7.4V)
橙色线 → 信号线 (PCA9685)
```
