# Reachy Mini 依赖清单

## 系统依赖

```bash
# 更新软件源
sudo apt update
sudo apt upgrade -y

# 基础工具
sudo apt install -y python3-pip python3-smbus i2c-tools
sudo apt install -y git wget curl

# 图像处理
sudo apt install -y libopencv-dev python3-opencv

# 音频处理
sudo apt install -y portaudio19-dev python3-pyaudio

# 树莓派专用
sudo apt install -y raspberrypi-kernel-headers
```

---

## Python 依赖

### 核心依赖

```bash
# 舵机驱动
pip3 install adafruit-circuitpython-pca9685

# 基础库
pip3 install numpy
pip3 install scipy

# 图像处理
pip3 install opencv-python
pip3 install pillow
```

### 语音相关

```bash
# 语音识别 (离线)
pip3 install speechrecognition

# 唤醒词检测 (替代Snowboy)
pip3 install pvporcupine

# 麦克风阵列驱动
pip3 install respeaker
```

### 机器学习 (可选)

```bash
# 人脸检测
pip3 install face-recognition
pip3 install dlib

# 语音助手 (可选)
pip3 install duckduckgo
```

## 快速安装脚本

```bash
#!/bin/bash
# install.sh

echo "========================================="
echo "Reachy Mini 依赖安装脚本"
echo "========================================="

# 系统依赖
echo "[1/5] 安装系统依赖..."
sudo apt update
sudo apt install -y \
    python3-pip \
    python3-smbus \
    i2c-tools \
    git \
    libopencv-dev \
    portaudio19-dev

# I2C 配置
echo "[2/5] 启用I2C接口..."
sudo raspi-config nonint do_i2c 0

# Python 依赖
echo "[3/5] 安装Python依赖..."
pip3 install --user \
    adafruit-circuitpython-pca9685 \
    numpy \
    scipy \
    opencv-python \
    pillow \
    speechrecognition \
    pvporcupine

# 摄像头
echo "[4/5] 配置摄像头..."
sudo modprobe bcm2835-v4l2

echo "[5/5] 重启系统..."
echo "========================================="
echo "✓ 安装完成!"
echo "请运行: sudo reboot"
echo "========================================="
```

## 验证安装

```bash
# 检查I2C
sudo i2cdetect -y 1

# 检查Python包
python3 -c "import cv2; print('OpenCV:', cv2.__version__)"
python3 -c "import numpy; print('NumPy:', numpy.__version__)"

# 检查摄像头
libcamera-hello

# 检查麦克风
arecord -l
```

## 开启树莓派接口

```bash
sudo raspi-config
```

在配置界面中:

```
Interface Options → I2C → Yes
Interface Options → Camera → Yes
Interface Options → SSH → Yes
Interface Options → Remote GPIO → Yes
```

重启后生效:

```bash
sudo reboot
```
